# ZuluSCSI GitHub Organization page

ZuluSCSI is a family of advanced, high performance SCSI emulators, consisting of both [firmware](https://github.com/ZuluSCSI/ZuluSCSI-firmware/) and [hardware](#open-source-hardware). 

Pre-assembled and tested ZuluSCSI Blaster and Ultra Wide OSHW boards are also available for purchase from the [Rabbit Hole Computing Online Shop](https://shop.rabbitholecomputing.com/collections/zuluscsi) and our [authorized resellers](http://zuluscsi.com/wheretobuy).

## Firmware Releases

Visit https://github.com/ZuluSCSI/ZuluSCSI-firmware/releases/latest to access the latest and historical ZuluSCSI firmware releases. ZuluSCSI firmware is GPLv3-licensed Open Source Software. 

## Development

ZuluSCSI firmware development primarily takes place at https://github.com/ZuluSCSI/ZuluSCSI-firmware, where you can also ask questions in the Discussion section, or report firmware issues in the issues section
